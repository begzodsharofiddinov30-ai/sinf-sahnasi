# Audio fayllar

Dars sahnalariga oldindan yozilgan ovoz qo‘shish uchun:

1. Faylni shu papkaga qo‘ying, masalan `public/audio/1-sinf/salom.mp3` (MP3, mono, 64–96 kbit/s tavsiya etiladi).
2. Dars faylida sahnaga yozing: `audio: 'audio/1-sinf/salom.mp3'` (yoki `story` sahifasiga).
3. `npm run validate:content` fayl borligini tekshiradi.

Faqat o‘zingiz yozgan yoki CC0 / jamoat mulki bo‘lgan ovozlarni ishlating va ASSETS.md ga yozing.
Internet manzillari (http://…) ruxsat etilmaydi — dars oflayn ishlashi kerak.
